## Bugs and remaining limitations

### Confirmed bugs

Moderator edit initially failed with HTTP 400, `Unknown study-space field: id.` `SpaceEditor.submit` spread the full selected-space object into the PATCH payload, including server-managed fields such as `id` and timestamps, while the backend rejects unknown fields. Fixed [`ModeratorDashboard.jsx`](../client/src/pages/ModeratorDashboard.jsx) to send only writable space fields and added [`moderator-space-edit.test.jsx`](../client/src/test/moderator-space-edit.test.jsx) to verify the update payload. The live retry succeeded and the edited values were read back from the backend.
